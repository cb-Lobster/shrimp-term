# ShrimpTerm v0.2.0

一个带 AI 助手的极简 SSH 终端。多标签终端 + 每个连接独立的运维助手 —— **所有命令都打在你看得见的终端里**。

> 本版是第一个可分发的版本：有安装包、有图标、有版本号。

## 安装

下载 `ShrimpTerm Setup 0.2.0.exe`（80 MB）后双击安装。

- **按当前用户安装**（`%LOCALAPPDATA%\Programs\ShrimpTerm`），**不需要管理员权限**
- 安装时可自定义路径；桌面与开始菜单快捷方式自动创建
- 卸载：设置 → 应用 → ShrimpTerm（**用户数据保留**，重装后连接还在）

### 首次运行会被 Windows 拦一下？

本版**未做代码签名**，Windows SmartScreen 会提示"未知发布者"。点「更多信息」→「仍要运行」即可。

下载后可以先核对文件完整性：

## 这一版做了什么

**终端**
- 真 SSH 会话、多标签拖拽排序、镜像输入、终端内搜索
- 中文输出按会话编码解码（iconv），不再乱码

**助手（每会话一个）**
- 只能在**当前会话**里打字：你看着它敲，输出你自己看
- 命令结束用**哨兵**判定，不是靠固定等待：快命令秒回、慢命令不截断、返回真实退出码
- 输出自动去掉 ANSI 转义与命令回显
- 单条命令 30 秒超时（`SHRIMP_CMD_TIMEOUT` 可配），超时如实回报、绝不重试

**多段对话**
- 「新会话」新建一段对话，旧的保留
- 「历史会话」列出这台机器的全部对话，可切回继续追问、可删除
- 对话按主机归档，关闭标签或重启都不丢

**工程**
- 运行时数据放 `%APPDATA%\ShrimpTerm`（不再写在安装目录，装到哪都能跑）
- `npm run check`：语法 / 回归用例 / IPC 契约 / 敏感残留 / 核心函数定义 五项自检
- `npm run installer`：一条命令产出安装包

## 已知限制（如实说明）

1. **未签名** —— 需要 SmartScreen 手动放行；无代码签名证书
2. **仅 Windows 10+** —— Electron 33 不支持 Win7/8；macOS/Linux 未提供构建
3. **只支持 POSIX shell 远端** —— 哨兵依赖 `printf` 与 `$?`，连 Windows 远端时无法判断命令结束
4. **一次只发一条命令行** —— 多行脚本需自行用 `&&` / `;` 拼接
5. **没有三闸门** —— 破坏性命令目前只靠"全程可见"约束，白名单/预览/执行后复检在下一版
6. **助手上下文保留 8 轮** —— 长排查会丢早期结论
7. **API Key 明文存本地** —— 未用系统凭据加密（仅本机可读，但不算安全存储）
