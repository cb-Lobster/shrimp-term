# ShrimpTerm v0.3.0

一个带 AI 助手的极简 SSH 终端。多标签终端 + 每个连接独立的运维助手 —— **所有命令都打在你看得见的终端里**。

> 本版是**界面改版**：右侧助手重新排版、深色主题换代，并修掉了一个"命令卡片看不见"的真实缺陷。
> 功能与 v0.2.0 一致，没有新增能力。

## 安装

下载 `ShrimpTerm Setup 0.3.0.exe`（80 MB）后双击安装。

- **按当前用户安装**（`%LOCALAPPDATA%\Programs\ShrimpTerm`），**不需要管理员权限**
- 安装时可自定义路径；桌面与开始菜单快捷方式自动创建
- 覆盖安装会保留 `%APPDATA%\ShrimpTerm` 下的连接与对话记录
- 卸载：设置 → 应用 → ShrimpTerm（**用户数据保留**，重装后连接还在）

### 首次运行会被 Windows 拦一下？

本版**未做代码签名**，Windows SmartScreen 会提示"未知发布者"。点「更多信息」→「仍要运行」即可。

## 这一版改了什么

**修掉一个真缺陷：命令卡片在深色主题下基本看不见**

`.msg.act` 的颜色是硬编码的 `#4a4a46`，没走主题变量。深色主题（`#1b1f27` 底）下对比度只有 **1.8:1**（WCAG AA 要求 4.5:1），命令那一行几乎是黑的；浅色主题下 9:1 完全正常 —— 所以这个 bug 只在开深色的人那里出现，长期没被发现。

这正好顶在产品的"命令必须看得见"上：助手敲了什么，你得看得见。所以不是调个色，是补了一套语义变量（`--code-bg` / `--code-text` / `--accent-line` / `--warn-soft`），顺带治了 `.amsg.act` 和标签页关闭按钮红底两处同类问题。

**右侧助手重新排版**

- 助手消息改成带描边的气泡，用户消息改成强调色右对齐气泡 —— 长对话里能分清谁在说话
- 命令独立成深色卡片，左边一条强调色竖线做定位锚点
- 表格、代码块统一走 code 变量，表头不再抢戏

**配色与密度**

- 深色主题换成 GitHub Dark 调色板（整块变量替换，不是零散覆盖）
- 标题栏 38→30、工具栏 34→30、标签行 36→32、左栏 256→242、状态点 6→7px
- 终端行距 1.3（走 `Terminal` 构造参数，不是 CSS —— 用 CSS 会让字符网格和光标位置错开）

**工具栏图标化**

"本会话 / 会话设置"两个文字按钮改成 `▥` / `⚙` 图标，同时补了 `title` 提示 —— 只留图标不给出处，等于逼人猜。

## 已知限制（如实说明，与 v0.2.0 相同）

1. **未签名** —— 需要 SmartScreen 手动放行
2. **仅 Windows 10+** —— macOS/Linux 未提供构建
3. **只支持 POSIX shell 远端** —— 哨兵依赖 `printf` 与 `$?`
4. **一次只发一条命令行** —— 多行脚本需自行用 `&&` / `;` 拼接
5. **没有三闸门** —— 破坏性命令目前只靠"全程可见"约束
6. **助手上下文保留 8 轮**
7. **API Key 明文存本地** —— 未用 `safeStorage` 加密

## 下一步
