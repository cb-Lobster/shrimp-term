# ShrimpTerm v0.6.0

- 主机库采用顶部标签、侧边导航、分组卡片与可切换的网格、列表。连接后收起主机库导航，终端搜索与会话工具按需打开。
- 顶部 SFTP 跟随当前窗格，可浏览远端目录、上传下载单个文件、查看进度和取消。文件通过独立的 SFTP 通道传输。
- `Ctrl+K` 搜索已有标签、主机和操作。`Ctrl+Shift+F` 搜索终端输出。常用命令可保存、编辑和复制。
- Agent 继续通过独立的后台 SSH 通道运行，结果记录在「后台任务」。

本地测试包含真实 SSH 和 SFTP 协议回环，覆盖目录读取、文件内容、取消、同名保护和前台通道隔离。Windows 打包和日常操作见 [README](../README.md)。
